* Examples
    - Demo: [documentation](examples/documentation/)
        Generate documentation for a Flask REST service by handing the
        agent a template (sections, TODOs, diagram placeholders, links)
        instead of a blank page.
    - Demo: [project-analysis](examples/project-analysis/)
        Let the agent analyze an existing project, record its findings
        in a report, and then fix the problems one at a time, reviewing
        each change as a diff.
    - Demo: [requirements-analysis](examples/requirements-analysis/)
        Convert a free-form prose specification into user stories with
        acceptance criteria, and see why structured requirements are
        easier to review.
    - Demo: [development](examples/development/)
        Implement a REST service from user stories: generate a plan,
        review it manually, then implement it one story at a time.
    - Demo: [refactoring](examples/refactoring/)
